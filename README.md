# 중소벤처기업부(MSS) 소개 & 혜택 자가진단 웹 애플리케이션

대한민국 중소기업, 벤처·스타트업, 소상공인의 성장과 도약을 지원하는 **중소벤처기업부(Ministry of SMEs and Startups)**를 국민의 눈높이에서 쉽고 친근하게 소개하고, **"나는 이 기관으로부터 어떤 도움을 받을 수 있을까?"**를 직접 진단해볼 수 있는 인터랙티브 웹 앱입니다.

---

## 🚀 실행 방법 (초간단 실행)

1. 폴더 안에 있는 **`index.html`** 파일을 마우스로 **더블클릭**합니다.
2. 기본 웹 브라우저(Chrome, Edge, Whale 등)에서 즉시 실행됩니다.
   - **별도의 웹 서버나 설치 프로그램(Node.js, npm, Python 등)이 전혀 필요하지 않습니다.**
   - 로컬 파일(`file:///`) 환경에서도 CORS 오류 없이 100% 정상 작동하도록 순수 바닐라 HTML5, CSS3, JavaScript로 제작되었습니다.

## 🌟 핵심 기능 및 구성

### ✨ 1. [신규 추가] "나는 중기부로부터 어떤 도움을 받을 수 있을까?" 1분 맞춤 진단 설문
방문한 국민이 자신의 상황과 고민을 3단계 체크리스트로 답하면 맞춤 혜택을 즉시 진단해 드립니다.
- **Q1. 현재 나의 상태/역할**:
  - 예비·청년 창업자 / 소상공인·자영업자 / 스타트업·벤처기업 / 중소 제조기업 / 일반 국민·소비자
- **Q2. 가장 절실한 지원 분야**:
  - 자금·정책금융, 판로·소비진작, AI·스마트화, 위기극복·재도전, 공정거래·기술보호, 해외수출
- **Q3. 추가 우대조건 체크**:
  - 만 39세 이하 청년, 창업 3년 이내 초기, 비수도권 지방/전통시장, 고금리 채무 부담 여부
- **🎯 맞춤 진단 결과 리포트 제공**:
  - **진단 유형 판정**: `[청년·혁신 기술창업가]`, `[골목상권 지킴이 소상공인]`, `[글로벌 딥테크 벤처]`, `[스마트 제조혁신 강소기업]`, `[스마트 상생 소비 국민]`
  - **최대 지원 규모 및 공식 신청 포털, 1357 전문상담 안내**
  - **맞춤 추천 지원사업 4선 (상세 혜택 및 신청 링크 ↗)**
  - **지금 바로 시작하는 3단계 실천 로드맵 (Action Guide)**
  - **진단 결과 인쇄 및 PDF 저장(`window.print()`), 요약 복사, 다시 하기 지원**

### 2. 한눈에 보는 중기부 소개 & 핵심 지표
- **9988 위상**: 대한민국 전체 기업의 **99.9%**, 일자리의 **81.3%**를 책임지는 중소기업·소상공인의 역할 시각화
- 중소벤처기업부의 비전, 미션 및 국민이 체감하는 3가지 핵심 변화 안내
- 실시간 키워드 검색창 (인기 검색어 태그 클릭 시 해당 정책 및 뉴스로 즉시 이동)

### 3. 국민 눈높이 5대 핵심 업무 (인터랙티브 탭)
1. **소상공인·전통시장**: 온누리상품권 10% 상시 할인, 경영안정 정책자금, 원스톱 폐업·재도전(희망리턴패키지), 스마트상점
2. **창업·벤처육성**: 민간투자연계 TIPS(팁스), 초격차 스타트업 1000+, 청년창업사관학교, 모태펀드
3. **중소기업·스마트제조**: 제조 AI 스마트공장 보급, R&D 혁신바우처, 규제자유특구
4. **글로벌 수출·판로**: K-브랜드 보호, 수출바우처, 동행축제 판로 개척
5. **공정거래·기술보호**: 납품대금 연동제 법제화, 기술탈취 원스톱 권리구제 신문고, 기술자료 임치

### 4. "나에게 맞는 정책 찾기" (Interactive Policy Finder)
- **대상 선택**: 예비·청년 창업자 / 소상공인·자영업자 / 중소·벤처기업 대표 / 일반 국민·소비자
- **분야 선택**: 자금/대출, 소비할인/판로, 기술개발/스마트AI, 폐업지원/재도전
- 조건에 맞는 맞춤형 사업 즉시 필터링 및 **상세 팝업 모달 & 공식 신청 링크** 제공

### 5. "온누리상품권 혜택 시뮬레이터" (Interactive Calculator)
- 월 지출 금액(5만 원 ~ 200만 원) 슬라이더 조절
- **10% 즉시 충전 할인액(연간)** 및 **전통시장 소득공제(최대 40~50%) 인정액** 실시간 자동 계산

### 6. 최신 뉴스 기사 & 정책 동향 (실제 기사 URL 삽입)
- 연합뉴스, 대한민국 정책브리핑, 머니투데이 등 언론사별 최신 보도 및 공식 브리핑 수록
- 카테고리 필터링(전체, 창업·벤처, 소상공인, 중소기업, 글로벌·상생) 및 실시간 뉴스 검색
- 각 뉴스 카드별 **"기사 원문 보기" (공식 언론사 및 정부 포털 외부 링크 연결)**

### 7. 알기 쉬운 정책 용어 사전 (Glossary)
- TIPS, 온누리상품권, 모태펀드, 납품대금 연동제, 규제자유특구, 스마트공장 등 생소한 경제 정책 용어를 3줄로 알기 쉽게 해설

### 8. 편의 기능
- **다크 모드 / 라이트 모드 전환** (설정 저장 지원)
- **100% 모바일 반응형 웹 디자인** (스마트폰, 태블릿, PC 완벽 대응)
- 중소기업 통합 콜센터 안내 (**국번없이 1357**)
